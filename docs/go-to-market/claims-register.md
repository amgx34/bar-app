Date: 2026-11-25. Branch `rebuild/foundation`. Drafted for the owner. Documents only: no page, config or code was edited, and every "suggested wording" below is a suggestion for the owner, not an edit.

**Verdicts.** TRUE: the code, a test or a doc backs it as worded. PARTLY: true in part; the limit is named. UNSUPPORTED: searched for and not found, or the code contradicts it. UNVERIFIED: cannot be checked from the repo (a vendor's terms, a staffing promise, a legal point, a number nobody measured). Per the plan, code that exists but was never run against a real account is UNVERIFIED, not TRUE.

**How to read it.** Section A is every claim Rail makes in public today. Section B is what the strategy intends to say. Section C ranks what to fix first. Section D lists what could not be checked and the sources. All file references are in `/Users/xavierdichiara/bar-app`. Line numbers are as of this branch on 2026-11-25.
