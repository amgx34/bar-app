# Dev setup (macOS)

- `npm install`; copy `.env.local` and `.env.development.local` by hand (gitignored). `npm run dev` serves `/login` with 200.
- The Windows "Ready, then exit" (Task 6 Step 6) did not reproduce on macOS.

## Seeding the dev project

    npm run dev
    curl -c jar -X POST localhost:3000/api/demo      # no body, no bot check; returns {"redirectTo":"/app/dashboard"}
    curl -b jar localhost:3000/app/dashboard         # 200, shows "Tipsy Tavern"

The route creates a demo user and org (slug prefix `demo-tipsy-tavern-`), seeds it, and signs in via cookie.
Demo orgs are swept after 24 h by `/api/cron/2touch`. Per-IP rate limit applies.
