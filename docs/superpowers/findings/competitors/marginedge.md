# MarginEdge (marginedge.com) — competitor record
All facts read on 2026-11-25 from public pages. Sources: H = https://www.marginedge.com ; P = https://www.marginedge.com/pricing ; M = https://www.marginedge.com/mobile (search snippet only; page body not fetched) ; HW = https://www.marginedge.com/how-it-works (search result only, not fetched).

1. Target: independent restaurants, multi-unit groups, franchises, restaurant accountants; cites 12,000+ restaurants. Bars not named. (H)
2. Headline: "AI runs the numbers. You run the restaurant." and "One AI-powered platform for your whole back office, whether you run one restaurant or fifty." (H)
3. Nav: Solutions, How It Works, Pricing, About, Resources; utility: Refer a Friend, Visit Help Desk, Log In. (H)
4. Pricing (P): per location, flat. $350/location/month monthly; $315/location/month on annual ($3,780/yr, paid upfront, "non-refundable if you cancel early"). Add-ons: Liquor Smart Scale (Freepour) +$150/mo ($135 annual); SmartPrep +$95/mo ($85.50 annual); MarginEdge Card free to enroll. Toast API pass-through fee 10% of subscription per location/month (FAQ). Toast Restaurant Mgmt Suite $50/location/mo billed by Toast. Sales tax excluded. Onboarding fees excluded and amounts not shown (3 packages for 1-4 locations in a PDF; 5+ custom). Groups: tailored quotes.
5. Top features (H): invoice automation (AI + human reviewers code line items); food cost control (daily P&L, price-change alerts); "Tom" AI assistant plus AI connector for ChatGPT/Claude/Gemini. Also recipe costing, inventory, sales forecasting, bill pay (free, US only).
6. Onboarding (H, P): hands-on, guided by former operators; "up and running within a few weeks"; paid packages. Not purely self-serve. Add-on hardware: Freepour smart scale ($500 fee if not returned).
7. Integrations (H): POS Toast, Square, NCR Aloha, SpotOn; accounting QuickBooks, Xero, Sage; scheduling 7shifts; distributors Gordon Food Service, Ben E. Keith, Shamrock, US Foods.
8. Mobile: yes. Free iOS and Android app; photo capture of invoices (help.marginedge.com/hc/en-us/articles/218822667-Uploading-Invoices; M). Home page does not mention it.
9. Coverage vs Rail:
   - Inventory/COGS: yes (recipe costing, inventory, food cost, daily P&L) (H)
   - Payroll and tip pooling: no for payroll/tips. Only labor-cost reporting pulled from scheduling/payroll systems (7shifts); no tip-pool evidence found (H; search snippet). Treat tip pooling as unverified-absent.
   - Sales analytics: partial/yes via POS sync, forecasting, multi-unit comparison (H)
   - Supplier/rep ordering: partial; invoice capture, distributor integrations, bill pay; ordering workflow unverified (H)
10. Dealbreakers: $350/location/mo is high for a single bar (P); annual prepay non-refundable on early cancel (P); unstated onboarding fees (P); 10% Toast API fee (P); hardware add-on fee $500 if scale unreturned (P).
