# WISK (wisk.ai) — competitor record

All lines: read on 2026-11-25. Sources: H = https://www.wisk.ai (home), P = https://www.wisk.ai/pricing, S = web search snippets (apps.apple.com/app/id1077887014, wisk.ai/price, wisk.ai/new-pricing). Page text came through WebFetch's summarizer, so quotes are as returned by it.

1. Target: bars, restaurants, hotels; also hospitality groups, fine dining, coffee shops, franchises, QSR, golf/country clubs (H).
2. Headline: "Streamline inventory, invoicing, purchasing, recipe costing, and COGS with WISK's all-in-one platform." (H)
3. Nav: Features, Integrations, Pricing, Resources, Learn, Contact Us, Support, Log In, Book a demo; For Bars / For Restaurants / For Hotels (H).
4. Pricing (P): subscription, per location per month (per property for multi-outlet). Beverage / Food / F&B bundle monthly: 1 outlet $249 / $249 / $399; 2-3 outlets $499 / $499 / $799; 4-7 $899 / $899 / $1,499; 8-10 $1,250 / $1,250 / $1,999; 11+ custom. Annual saves ~17-20%; quarterly has "modest premium". Single venue limits: 1,000 SKUs, 75 AI invoices/mo, 5 users. One-time implementation fee: $750 (single bev/food), $1,250 (bundle), up to $3,500-4,500 (8-10), from $7,500 enterprise; page contradicts itself (says 4-10 outlet annual plans include implementation). Search snippets (S) show older/other figures ($199 Bar Essentials, $399 F&B Professional) — unverified which is current. Home (H) shows a Black Friday offer: 15 months for 12, $0 setup, free Bluetooth scale, ends Nov 30.
5. Top features (H): (a) inventory counting incl. split counts among users, Bluetooth scale; (b) automated/AI invoice processing; (c) variance reports, COGS dashboards, recipe costing, sales-based purchasing/ordering.
6. Onboarding (H, P): demo/sales-led ("Book a demo"); no free trial; paid implementation fee; 60-day money-back guarantee (P).
7. Integrations (H, S): Toast, Lightspeed named on home; search snippet adds Agilysys, Aldelo, Aloha, Clover, Square, TouchBistro, SmartTab; QuickBooks Online, vendor integrations, Slack, Zapier, Mailchimp, Notion. "50+" POS on home vs "60+" on pricing. Full POS set may be tied to higher tier (S, unverified).
8. Mobile: iOS app "WISK.ai: Bar & Food Inventory" exists (S, apps.apple.com/app/id1077887014); offline use referenced and "Mobile app + Bluetooth scale" listed as core in all tiers (P). Home page itself describes no dedicated app (H).
9. Coverage vs Rail:
   - Inventory/COGS: yes (H, P)
   - Payroll and tip pooling: no — not mentioned (H); unverified beyond home page
   - Sales analytics: partial — variance/COGS/multi-venue reporting, POS-fed; no Z-report-style analytics seen (H)
   - Supplier/rep ordering: partial/yes — ordering, receiving, sales-based automated purchasing; "WISK suggested ordering" only on Multi-Outlet+ (H, P). No rep correspondence seen.
10. Dealbreakers (P): one-time implementation fee $750+; no free trial; cancellation is a request approved by billing team, not instant; no published data retention/export policy after cancellation; usage caps (SKUs, AI invoices, users); API/EDI only on Enterprise; optional Bluetooth scale hardware (no price listed). "No long-term lock-in" claimed (P).
